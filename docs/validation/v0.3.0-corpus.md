# v0.3.0 corpus validation

Date: 2026-11-05. Toolchain: Go 1.27.3, darwin/arm64, default build tags.
Audits ran sequentially. No corpus source or dependency source was modified.
This report uses public third-party modules only. It is a targeted convenience
sample, not an estimate of all Go code.

## G6 measurement before tuning (#55)

The sample contains **all 40 G6 findings** from x/tools v0.52.0, Cobra v1.10.2,
kin-openapi v0.152.0 and Chroma v2.27.0. Each method and its surrounding contract
was read before classification. A true positive must be removable forwarding
that adds no value; typed receiver binding and contract implementation count as
required adapters even when the body is short.

True positives: **0/40 (0%)**. Required adapters: **24**. Adds behaviour: **16**. Other: **0**.

The dominant false-positive category is required adapters. G6 now requires
unchanged parameter forwarding and preserves full named contracts from the
current package and direct imports, considering both value and pointer method
sets. This also removes nested transformations, constants, short guards and
assignments. Fixtures retain genuine forwarding, alias receivers and variadics;
prior standard/local-interface and multiline-body regressions still pass.

positive observations. This small, targeted sample does not establish broad
precision or recall. Both findings remain LOW.

registration imports. Doctor needs deliberate APIs for currently unexported
shared content/render/configuration helpers; the finding does not promise a
move-files-only refactor. Prefix-free graph communities remain deferred.

and `aggregate`, respectively. Synthetic fixtures cover a one-caller dispatcher,
multiple callers, direct/transitive cycles, receiver/interface families,
generated callers, tiny groups, whole-package support, and relative audit roots.

## Reproduction

Build Lagotto, download the listed module versions with `go mod download`, and
use each returned module directory as the scan root. Run one scan at a time:

```sh
go build -o /tmp/lagotto ./cmd/lagotto
/tmp/lagotto audit --format=json /path/to/module
GOWORK=off /tmp/lagotto packages --format=json /path/to/module
```

G6 before/after compares the same public source versions before and after commit
`5499ac0` plus the imported-interface calibration. G9 prefix counts are computed
from qualifying clusters before directory consolidation. The full raw reports
contain machine-specific paths; this document records the complete public hit
lists for G16, G17 and package-name G11, plus every sampled G6 finding.

Validation: `./check.sh` passed build, vet, golangci-lint, race tests and the
zero-finding self-audit. Every implementation commit received a fresh-agent code
review; review findings gained regression fixtures and a separately reviewed fix.
